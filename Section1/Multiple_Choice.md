Q1. What is Databricks primarily used for?

Options:

* a) Cloud Storage
* b) Data Engineering and Analytics
* c) Web Hosting
* d) CRM Systems

Correct Answer

✅ b) Data Engineering and Analytics

Reason : 

Databricks is a unified analytics platform built on Apache Spark that enables:

* Data Engineering
* Data Analytics
* Data Science
* Data Warehousing

-------------------------------------------------------------------------------------------------------------------------------------

Q2. Which feature in Databricks helps track and manage the lineage of data transformations?

Options:

* a) Delta Lake
* b) MLflow
* c) Data Lineage
* d) Unity Catalog

Correct Answer

✅ d) Unity Catalog

Reason

It automatically captures and aggregates column-level and table-level data lineage in real time across all workspaces, jobs, and notebooks.

Q6. What is the primary purpose of Delta Lake in Databricks?

Options:

* a) To provide real-time streaming capabilities
* b) To enhance data quality and reliability
* c) To manage API integrations
* d) To create visualization dashboards

Correct Answer

✅ b) To enhance data quality and reliability

Reason

Delta Lake provides:

* ACID Transactions
* Schema Enforcement
* Time Travel
* Data Versioning
